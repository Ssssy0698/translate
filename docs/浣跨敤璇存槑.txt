藏语翻译脚本 - 使用说明

==========================================
一、安装环境
==========================================

1. 安装Python 3.7或更高版本
   - 访问 https://www.python.org/downloads/
   - 下载并安装Python

2. 安装必要的Python包
   打开终端，运行以下命令：
   ```
   pip install selenium webdriver-manager
   ```

3. 安装Chrome浏览器
   - 访问 https://www.google.com/chrome/
   - 下载并安装Chrome浏览器

==========================================
二、运行脚本
==========================================

方法1：使用命令行参数
------------------------------------------
在终端中运行：
```
python3 藏语翻译脚本.py "གཙོ་ངོས།"
```

方法2：交互式输入
------------------------------------------
在终端中运行：
```
python3 藏语翻译脚本.py
```
然后按照提示输入藏语文本。

方法3：使用示例文本
------------------------------------------
直接运行脚本，不输入任何文本，按回车键使用默认示例文本：
```
python3 藏语翻译脚本.py
```

==========================================
三、输入藏语文本的位置
==========================================

1. 命令行参数：
   - 在运行命令时直接提供：python3 藏语翻译脚本.py "你的藏语文本"

2. 交互式输入：
   - 运行脚本后，会显示提示："请输入藏语文本 (直接回车使用示例文本 'གཙོ་ངོས།'):"
   - 在此处输入你的藏语文本，然后按回车

3. 示例文本：
   - 如果不输入任何内容直接按回车，脚本会自动使用示例文本："གཙོ་ངོས།"

==========================================
四、脚本工作流程
==========================================

1. 自动打开Chrome浏览器
2. 访问 https://nmt.utibet.edu.cn
3. 点击交换按钮（确保翻译方向为藏语→汉语）
4. 在输入框中输入藏语文本
5. 点击翻译按钮
6. 等待翻译完成
7. 获取并显示汉语翻译结果
8. 询问是否保存结果到文件

==========================================
五、注意事项
==========================================

1. 首次运行可能会自动下载ChromeDriver，需要网络连接
2. 脚本会显示浏览器窗口，可以看到自动化过程
3. 翻译过程需要3-5秒，请耐心等待
4. 确保网络可以访问 https://nmt.utibet.edu.cn

==========================================
六、故障排除
==========================================

问题1：提示"WebDriver初始化失败"
解决：检查是否安装了Chrome浏览器和Python包

问题2：提示"页面加载超时"
解决：检查网络连接，确保可以访问翻译网站

问题3：提示"元素找不到"
解决：网站可能已更新，需要更新脚本

问题4：ChromeDriver版本不匹配
解决：脚本会自动管理ChromeDriver，确保网络畅通

==========================================
七、示例
==========================================

示例1：翻译单个词语
```
python3 藏语翻译脚本.py "གཙོ་ངོས།"
```

示例2：翻译句子
```
python3 藏语翻译脚本.py "བོད་སྐད་དུ་བཤད་པ་རྣམས་ཡིག་སྒྱུར་བྱེད་པར་འདི་ནི་དཔེ་མཚོན་ཞིག་ཡིན།"
```

==========================================
八、输出结果
==========================================

脚本运行成功后，会显示：
```
============================================================
藏语原文: གཙོ་ངོས།
汉语翻译: 主页
============================================================
```

然后会询问是否保存结果到文件。
