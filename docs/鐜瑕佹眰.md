# 藏语翻译脚本 - 环境要求

## 系统要求

### 1. 操作系统
- macOS (当前系统)
- Windows 10/11
- Linux (Ubuntu/Debian/CentOS等)

### 2. Python环境
- Python 3.7 或更高版本
- pip (Python包管理器)

### 3. 浏览器要求
- Google Chrome 浏览器 (最新版本)
- ChromeDriver (脚本会自动管理)

## 安装步骤

### 步骤1: 检查Python安装
```bash
python3 --version
```

如果未安装Python，请从 https://www.python.org/downloads/ 下载安装

### 步骤2: 安装必要的Python包
```bash
pip install selenium webdriver-manager
```

如果遇到权限问题，可以尝试：
```bash
pip install --user selenium webdriver-manager
```

### 步骤3: 安装Chrome浏览器
如果未安装Chrome浏览器，请从 https://www.google.com/chrome/ 下载安装

## 验证安装

### 验证Python包安装
```bash
python3 -c "import selenium; print('selenium版本:', selenium.__version__)"
python3 -c "from webdriver_manager.chrome import ChromeDriverManager; print('webdriver-manager可用')"
```

### 验证Chrome浏览器
确保Chrome浏览器已安装并可以正常启动

## 运行脚本

### 基本运行
```bash
python3 藏语翻译脚本.py
```

### 指定藏语文本
```bash
python3 藏语翻译脚本.py "གཙོ་ངོས།"
```

### 无头模式运行（不显示浏览器界面）
修改脚本中的 `headless=False` 为 `headless=True`

## 故障排除

### 常见问题1: ChromeDriver版本不匹配
- 脚本使用 `webdriver-manager` 自动管理ChromeDriver版本
- 如果遇到问题，可以手动下载ChromeDriver: https://chromedriver.chromium.org/

### 常见问题2: 网络连接问题
- 确保可以访问 https://nmt.utibet.edu.cn
- 检查防火墙设置

### 常见问题3: 元素找不到
- 网站结构可能已更新
- 检查控制台输出查看具体错误

## 脚本功能

### 主要功能
1. 自动打开翻译网站
2. 点击交换按钮确保翻译方向正确
3. 输入藏语文本
4. 点击翻译按钮
5. 获取并显示汉语翻译结果

### 支持特性
- 自动重试机制（最多2次）
- 详细的错误日志
- 上下文管理器确保资源正确释放
- 命令行参数支持

## 注意事项

1. **首次运行**：可能会自动下载ChromeDriver，需要网络连接
2. **浏览器窗口**：默认会显示浏览器窗口，可以看到自动化过程
3. **翻译时间**：需要等待网站处理翻译，通常3-5秒
4. **网络稳定性**：需要稳定的网络连接访问翻译网站
